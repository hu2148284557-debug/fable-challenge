# 挑战 Fable 5.2（对打网页）

这是开源游戏 [killfield](https://github.com/Cichlider/killfield)（作者 Cichlider / Rekursion，坦克动荡的复刻，MIT 协议）网页的**非官方改版**。原版网页上人可以打作者的神经网络人机 Hybrid；这一页在对手里多加了一个 **Fable 5.2**——Claude Fable 5.2 在 Hybrid 的基础上写的打人版程序。

## 怎么玩

1. 点 **Play**，对手（Opponent）选 **Fable 5.2**（默认就是）。
2. 点 **记录对局 / Recorded run** 开打。记录对局用的是和原版排行榜一样的设置：对手不延迟出招，开局让步最多 0.5 秒。一场最多 200 局。
3. 打完点 **结束记录**。然后可以：
   - **下载录像**：存下一个 `.json` 录像文件；
   - **观看录像**：直接在本页回放。
4. 在 **Replay** 里打开录像，点 **Export MP4** 就能导出视频（清晰度可选）。

键盘：方向键或 WASD 移动，空格 / Q / M 开火，P 暂停，R 换地图，C 清比分。

不点“记录对局”也能直接打，只是不存录像。对手也可以换回原版的 Hybrid、Killfield、Laika，方便对比。**Watch** 里可以看 Fable 5.2 和 Hybrid 互打。

## 和原版不一样的地方

- 对手列表里多了 Fable 5.2（`src/fable-brain.js`）。
- 去掉了往作者排行榜提交成绩的入口，提交地址也删了。这一页不往任何地方发成绩。
- 打 Fable 5.2 的录像文件里对手写的是 `fable`，原版网页打不开这种录像，免得和作者排行榜的录像混在一起。在本页的 Replay 里能正常回放、导出。
- 游戏引擎（`kf_engine.wasm`）、Hybrid 的网络和权重（`assets/hybrid.*`）都是原版文件，一个字节没改。

## Fable 5.2 是怎么打的

底子还是 Hybrid 的网络：每一帧它给 18 个动作各打一个分。Fable 5.2 的程序只管一件事——**替它把子弹看远**。

天上的子弹之后怎么飞、怎么弹是算得准的，跟人接下来按什么键没关系。所以每一帧她都在一份引擎副本里，把“网络想出的这一招”往后推演一两秒：照这么走会不会被打中？会的话，就按网络的喜好换一招试，直到找到一招后面接得上活路的。网络想出的招本来就安全时，她一个字都不改。

她和 Hybrid 用的是同一个入口：坐同一个位置，每秒出 25 次招，每次 18 选 1，没有别的特权。她每一帧最多想几毫秒，只在这个网页里算，不联网。

## 在自己电脑上打开

网页必须通过 http 打开（直接双击 `index.html` 不行）。

- **Windows**：双击文件夹里的 `start.cmd`。它会开一个黑窗口，并在浏览器里打开网页；打的时候别关这个窗口，打完关掉就行。不用装任何东西。
- **别的系统**，或者不想用上面那个：装了 Python 的话，在这个文件夹里运行 `python -m http.server 8791`，再用浏览器打开 <http://localhost:8791/> 。

浏览器用 Chrome 或 Edge（导出 MP4 要用到它们的视频编码功能）。
